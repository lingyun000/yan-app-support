PRIVACY / DATA HANDLING

Privacy policy

Effective and updated October 1, 2026 · Yan macOS app 1.0

Text editing, formatting, encoding and data validation run on your Mac. Yan has no developer-operated content upload server, advertising or analytics SDK, and no app account.

1. Who maintains this app

Yan is maintained by lingyun000. Contact the developer through GitHub Issues. Issues are public: remove personal information, tokens, passwords and real business data before posting.

2. Data stored on your Mac

  • Editor settings, favorites, recent tools and recent-file records stay in local preferences.
  • When draft autosave is enabled, unsaved text and editor sessions stay in the app’s Application Support folder. Drafts are not encrypted by the app. Manage them by closing tabs or using draft controls in settings.
  • macOS security-scoped bookmarks may retain access to files you select so they can be reopened. These bookmarks are not sent to the developer.
  • HTTP requests, environments, credentials and history may be saved locally. Request payloads and environment configuration use AES-GCM with a key in this Mac’s Keychain. Index metadata such as names, groups and URLs is not all encrypted. You control copying and exporting; default redaction may not identify every custom sensitive field.
  • Private HTTP sessions do not save the current tab or new history. They do not delete existing history or stop requests, copies or exports you initiate.

3. When the app uses the network

ActionRecipient and data
Send an HTTP requestThe server you specify receives the URL, headers, authentication, body and selected attachments. Its policy controls retention. Plain HTTP does not protect transmitted content.
Refresh public IP informationipify and ipapi.is see the connection’s public IP; IP intelligence queries also include the queried address. Results describe network exit, region and provider. No precise device location is requested. The providers publicly state that API query IPs are not logged; policies can change.
Download optional fontsGitHub / GitHub Raw receives font requests and ordinary connection information such as IP, only when you choose to download. Provider and hosting policies apply; see GitHub’s privacy statement.
Preview Markdown / HTMLExternal images, styles or other resources referenced by a document may contact their servers. Avoid previewing untrusted sensitive documents.
Open support or external links; submit feedbackYour browser visits the selected site. GitHub hosts Pages and Issues. Feedback is sent only when you submit it.

Yan does not automatically send editor text, HTTP credentials or files to the developer. The operating system, App Store and servers or websites you choose may process data under their own policies. These connections are not used for cross-app advertising tracking.

4. Permissions and security

The App Store version uses macOS App Sandbox, accessing its container and files you select, with outgoing network access. It does not request Full Disk Access, Accessibility, camera, microphone, contacts or precise-location permission. macOS may still prompt when protected resources are accessed.

Drafts, exports and indexes may contain sensitive content. Use system login protection, FileVault and suitable backups. The HTTP encryption key does not migrate with a normal database copy. Losing the original Keychain can make old records unreadable.

5. Deletion, choices and feedback

You can disable draft autosave, clear recent files, delete HTTP history and saved requests, use private sessions, remove downloaded fonts and inspect storage locations in settings. Clearing cache does not automatically erase all drafts, HTTP data, preferences or Keychain items. There is no online app account to delete. For content you send to a server or GitHub, use the recipient’s deletion controls or contact them.

6. Policy updates

This page is updated and dated when app features or services change. Public repository history records changes. Contact us through GitHub Issues without posting private information.

隐私政策

生效与更新日期：2026 年 10 月 1 日 · 适用于砚 macOS 应用 1.0

文本编辑、格式化、编码转换及数据校验在你的 Mac 上完成。砚没有开发者运营的内容上传服务器，没有广告和行为分析 SDK，也不要求注册应用账号。

1. 谁负责这个应用

砚由 GitHub 用户 lingyun000维护。应用支持与隐私问题通过本仓库的 Issues联系开发者。Issues 是公开的，请先删除个人信息、访问令牌、密码和真实业务数据。

2. 保存在本机的数据

  • 编辑器设置、收藏、最近工具及最近文件记录保存在应用自己的本地偏好设置中。
  • 启用草稿自动保存时，未保存的文本和编辑会话保存在应用的 Application Support 目录；这些草稿没有应用层加密。关闭标签页或在设置中清理草稿可管理正文。
  • 用户选择的文件访问授权可能以 macOS 安全作用域书签保存在本机，以便重启后重新打开文件。书签用于文件访问，不会发送给开发者。
  • HTTP 请求、环境变量、凭据和历史可以保存在本机。请求 payload 与环境配置使用 AES-GCM 加密，密钥位于这台 Mac 的 Keychain；请求名、分组、URL 等索引信息并非全部加密。导出或复制操作生成的内容由你决定，默认脱敏不保证识别所有自定义敏感字段。
  • HTTP 隐私会话不保存当前标签及本次历史；已有普通历史不会因此删除，主动发送、复制或导出仍由你控制。

3. 哪些操作会联网

操作接收方与发送内容
发送 HTTP 请求你指定的服务器接收 URL、Header、认证、正文与所选附件。对方的保存方式取决于其政策；请确认目标地址。非 HTTPS 请求不能保护传输内容。
主动刷新公网 IPipify 和 ipapi.is 接收网络连接的公网 IP，IP 情报查询还会包含所查询的 IP。用于显示网络出口、地区和运营商等结果，不访问系统精确定位。相关服务公开说明不记录 API 查询 IP；服务政策可能更新。
下载可选字体GitHub / GitHub Raw 接收字体文件请求和通常的连接信息，例如 IP。仅在你选择下载时发生。字体提供方和托管平台的政策适用；见GitHub 隐私声明。
Markdown / HTML 预览预览中由文档作者引用的外部图片、样式或其他网络资源可能访问对应服务器。不要预览不可信的敏感文档。
打开支持页面、外部链接或提交反馈浏览器访问所选择的网站。GitHub Pages 与 Issues 由 GitHub 托管；反馈只在你主动提交时发出。

砚不会自动把编辑器文本、HTTP 凭据或文件传给开发者。操作系统、App Store、你选择的服务器与网站可能按各自政策处理数据。砚不将这些连接用于跨应用广告追踪。

4. 权限与安全

App Store 版本使用 macOS App Sandbox，只访问应用容器及用户选择的文件，并允许工具所需的出站网络请求。不会要求完整磁盘访问、辅助功能、相机、麦克风、联系人或精确定位权限。macOS 自身仍可能在访问受保护资源时显示权限提示。

本机草稿、导出文件和索引可能含敏感内容；请配合系统登录保护、FileVault 与合适的备份策略使用。HTTP 加密密钥不会随普通数据库复制迁移到另一台电脑，丢失原钥匙串可能导致旧记录无法解密。

5. 删除、选择和反馈

你可以关闭草稿自动保存、清除最近文件、删除 HTTP 历史和保存请求、使用隐私会话、卸载已下载字体，并在设置中查看本地存储位置。清除缓存不会自动删除全部草稿、HTTP 数据、偏好设置或 Keychain 项。应用没有线上账户，因此不需要账户注销操作。对于你主动上传到目标服务器或 GitHub 的内容，请按接收方的功能与政策删除或申请处理。

6. 政策更新

应用功能或服务发生变化时，这个页面会更新并注明日期。历史修改可在公开仓库中查看。隐私问题请通过反馈入口联系。
