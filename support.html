Getting started

  1. Open a file with ⌘O or drag a text file into the editor. Use ⌘N for a new tab and ⌘S to save.
  2. Choose the appropriate language or tool and format with ⇧⌘F. Find with ⌘F and replace with ⌥⌘F.
  3. Open More Tools to search tools, use favorites and switch workspace tabs.
  4. In HTTP, enter a destination, select a method and body, then send. Start with your own test server and sample data.

Common questions

Is my text uploaded?

Editing, formatting and conversion run locally. HTTP requests, public-IP checks, optional font downloads and external preview resources use the network. Read the privacy policy for details.

Why can’t I reopen a file?

Sandbox access comes from selecting the file. If a file moves, is deleted or its authorization expires, use ⌘O to select it again. Preserve unsaved drafts first.

Why did an HTTP request fail?

Check the URL, server, proxy, authentication and certificate. Yan does not bypass HTTPS certificate verification. Plain HTTP exposes transmitted content; use HTTPS when possible.

How do I delete local data?

Inspect cache and draft folders in settings. Close editor tabs, clear recent files and delete HTTP history or saved requests using their controls. Clearing cache does not delete all persistent data. Private HTTP sessions affect the current tab and new history.

Why can’t a copied database be decrypted?

The HTTP key stays in the original Mac’s Keychain and does not move with an ordinary database copy. Keep the original Keychain and backups. Use redacted exports when sharing requests, and check their content.

What system do I need?

macOS 13 or later. No app account is required. Some features need the network. Large-file performance mode may disable features such as highlighting or undo.

从这里开始

  1. 用 ⌘O 打开文件，或把文本文件拖入编辑器；⌘N 新建标签，⌘S 保存。
  2. 选择对应语言或工具，按 ⇧⌘F 格式化；⌘F 查找，⌥⌘F 替换。

  4. HTTP 工具中填写目标地址、选择方法和正文，再主动发送。首次尝试建议用自己的测试服务器和示例数据。

常见问题

编辑的文本会上传吗？

编辑、格式化和转换在本机执行。HTTP 发送、公网 IP 刷新、下载字体及预览中的外部资源涉及网络；完整说明见隐私政策。

为什么重启后文件无法访问？

沙盒文件权限来自你选择文件时的授权。文件被移动、删除或授权失效后，请用 ⌘O 重新选择文件。先保留任何未保存的草稿。

HTTP 为什么请求失败？

检查目标地址、服务器状态、代理、认证和证书。工具不绕过 HTTPS 服务器证书校验。HTTP 明文请求会暴露传输内容，请尽量使用 HTTPS。

怎么删除本地数据？

在应用设置中检查缓存和草稿目录，并使用编辑器关闭标签、清除最近文件以及 HTTP 历史与保存请求的删除功能。清理缓存不会删除所有持久记录。HTTP 隐私会话只影响当前标签及新历史。

复制数据库后为什么不能解密？

HTTP 密钥保存在原 Mac 的 Keychain，不随普通数据库文件迁移。保留原钥匙串与备份；共享请求时优先使用应用的脱敏导出功能，并检查导出内容。

最低系统要求是什么？

macOS 13 或更新系统。应用无需注册账号；部分功能需要网络。大文件会使用性能模式，可能关闭高亮或撤销等功能。
