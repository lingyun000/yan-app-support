从这里开始

  1. 用 ⌘O 打开文件，或把文本文件拖入编辑器；⌘N 新建标签，⌘S 保存。
  2. 选择对应语言或工具，按 ⇧⌘F 格式化；⌘F 查找，⌥⌘F 替换。
  3. 从“更多工具”打开工具中心，使用搜索、收藏与工作标签切换常用工具。
  4. HTTP 工具中填写目标地址、选择方法和正文，再主动发送。首次尝试建议用自己的测试服务器和示例数据。

常见问题

编辑的文本会上传吗？

编辑、格式化和转换在本机执行。HTTP 发送、公网 IP 刷新、下载字体及预览中的外部资源涉及网络；完整说明见隐私政策。

为什么重启后文件无法访问？

沙盒文件权限来自你选择文件时的授权。文件被移动、删除或授权失效后，请用 ⌘O 重新选择文件。先保留任何未保存的草稿。

HTTP 为什么请求失败？

检查目标地址、服务器状态、代理、认证和证书。工具不绕过 HTTPS 服务器证书校验。HTTP 明文请求会暴露传输内容，请尽量使用 HTTPS。

怎么删除本地数据？

在应用设置中检查缓存和草稿目录，并使用编辑器关闭标签、清除最近文件以及 HTTP 历史与保存请求的删除功能。清理缓存不会删除所有持久记录。HTTP 隐私会话只影响当前标签及新历史。

复制数据库后为什么不能解密？

HTTP 密钥保存在原 Mac 的 Keychain，不随普通数据库文件迁移。保留原钥匙串与备份；共享请求时优先使用应用的脱敏导出功能，并检查导出内容。

最低系统要求是什么？

macOS 13 或更新系统。应用无需注册账号；部分功能需要网络。大文件会使用性能模式，可能关闭高亮或撤销等功能。
